# Yoga menu

A small, distraction-light menu for a deliberately limited set of YouTube yoga sessions.

## Publish with GitHub Pages

1. Create a public repository and add these files at its root.
2. In **Settings → Pages**, set **Source** to **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public URL when the first deployment finishes.
